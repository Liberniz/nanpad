# 司南 Nanpad 1.2.0

1.2.0 把资产台账从"服务器专属"扩展到"服务专属"：Cloudflare Worker、博客、自建邮箱都能记下来并定时做 HTTP 健康检查；服务器采集改为手动或自选周期，不再后台固定轮询；文档编辑器换成标准 Markdown；普通登录密码不再保存（请用 Bitwarden 等密码管理器），SSH 密钥与 API Key 保留。

## 本版变化

- 新增「服务」资产：记录 Cloudflare Worker、博客、邮箱服务等，支持 HTTP 可达检测与关键词匹配，异常时按通知设置提醒。侧边栏、搜索、标签、关系图、健康分全部接入。
- 服务器采集周期可配：默认仅手动采集，可选 5 / 15 / 30 / 60 分钟；解锁后仍立即采集一次。不再固定后台轮询。
- 消息推送新增 WxPusher 通道：配置 AppToken 与 UID（支持多个），重要提醒可推到微信。
- 文档编辑器换成标准 Markdown：源码 / 预览切换，旧 Tiptap 文档打开时自动迁移为 Markdown，图片沿用标准 `![alt](url)` 写法。
- 账号台账不再保存普通登录密码：网站账号只记账号名，SSH 密钥、API Key、Token 照常保留。浏览器插件不再读取密码值。

## 下载与升级

从本仓库 Releases 下载安装包，对照 `SHA256SUMS.txt` 核验文件：

- Windows x64：`Nanpad-1.2.0-setup.exe`
- macOS Apple Silicon（M 系列）：`Nanpad-1.2.0-arm64.dmg`

安装包目前没有代码签名。macOS 首次打开请右键点击应用 → 选择"打开"，确认一次后以后双击即可。升级前备份原数据，继续使用原主密码，不要删除 Nanpad 数据目录。

旧文档在首次打开时自动转为 Markdown，转换前原文完整保留；重复打开不会覆盖你的后续编辑。

## 验证范围与使用边界

- 329 个自动化单测、类型检查、i18n 校验、lint 与桌面构建全部通过；服务列表、添加表单经真机浏览器验证。
- 服务健康检查为简单的 HTTP GET（10 秒超时），不替代专业监控；关键词匹配只扫描约 1 MiB 响应体。
- WxPusher 推送依赖其公有 API 可用性；本机通知不受影响。
- 普通资产导出不包含加密凭据库，完整备份见安全文档。
