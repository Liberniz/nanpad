# 司南 Nanpad 1.2.1

1.2.1 是 1.2.0 的补丁版，只修一个问题：服务资产现在可以正常关联其他资产了。

## 本版变化

- 修复服务资产无法关联其他资产的问题：侧边栏「关联资产」、资产整理、文档绑定三个入口现在都能选到服务；之前因数据清洗被丢弃的服务关联不再丢失。

## 下载与升级

从本仓库 Releases 下载安装包，对照 `SHA256SUMS.txt` 核验文件：

- Windows x64：`Nanpad-1.2.1-setup.exe`
- macOS Apple Silicon（M 系列）：`Nanpad-1.2.1-arm64.dmg`

安装包目前没有代码签名。macOS 首次打开请右键点击应用 → 选择"打开"，或执行 `sudo xattr -rd com.apple.quarantine /Applications/Nanpad.app` 清除隔离标记。升级前备份原数据，继续使用原主密码，不要删除 Nanpad 数据目录。
